# Incubator

Plugins under development. Same folder layout as `plugins/`, but nothing here is listed in `.claude-plugin/marketplace.json`, so nothing here is installed on any machine. The catalog page shows these as "in development" so people can see what is coming and comment on the related issue.

To promote one: move the folder to `plugins/`, add an entry to `marketplace.json`, bump the version, open a pull request.
